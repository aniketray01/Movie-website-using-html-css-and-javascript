# 🎬 MovieBase - Film Discovery Tool

A cinematic platform designed for movie enthusiasts to search and explore their favorite films. This project highlights my ability to build interactive search tools and rich content displays.

## ✨ Features
- **Global Movie Search:** Instant search results with title and metadata.
- **Movie Details:** Dynamic rendering of ratings, cast, and plot summaries.
- **Cinematic UI:** High-contrast design inspired by modern streaming platforms.
- **Interactive Modals:** Detailed views for selected movies using pure CSS/JS.

## 🛠️ Tech Stack
- **HTML5:** Structured content delivery.
- **CSS3:** Advanced styling and custom animations.
- **Vanilla JavaScript:** Search logic and dynamic event handling.

## 🚀 Key Learning
Focused on optimizing client-side search algorithms and creating a high-fidelity user interface with pure CSS.
